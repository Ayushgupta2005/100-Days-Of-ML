# Dataset for this notebook

The Fashion MNIST CSV files are not kept in this repository because
`fashion-mnist_train.csv` is about 127 MB and GitHub does not allow a file
bigger than 100 MB.

Download the dataset from Kaggle and put it in a folder named `archive`
inside this folder, so that the paths used in the notebook work:

https://www.kaggle.com/datasets/zalando-research/fashionmnist

```
Day-46-Fashion-MNIST-CNN/
    archive/
        fashion-mnist_train.csv
        fashion-mnist_test.csv
    01_fashion_mnist_cnn.ipynb
```
